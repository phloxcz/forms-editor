Jak to zapojit do Nette projektu
1) composer require
   composer require phloxcz/forms-editor

2) config/common.neon
   extensions:
       editor: Phlox\Forms\Editor\EditorExtension

3) Formulář
   $form->addEditor('content', 'Obsah článku')
        ->setUploadRoute($this->link('Editor:wysiwygUpload'))
        ->setRequired('Zadejte obsah');

4) Presenter pro upload
   class EditorPresenter extends BasePresenter {
       use \Phlox\Forms\Editor\ImageUploadTrait;
   }

5) Layout / Latte šablona
   <link rel="stylesheet" href="{$basePath}/assets/wysiwyg.css">
   <script src="{$basePath}/assets/wysiwyg.js"></script>

6) Sanitizace hodnoty před uložením!
   $purifier = new \HTMLPurifier($config);
   $html = $purifier->purify($form->values->content);
