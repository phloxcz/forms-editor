# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | ✅ Aktivně podporována |

## Nahlášení bezpečnostní chyby

**Nehlaste bezpečnostní chyby přes veřejné GitHub Issues.**

Pošlete e-mail na adresu: **security@example.com**

Do zprávy uveďte:
- Popis zranitelnosti
- Kroky k reprodukci
- Potenciální dopad
- Váš návrh opravy (volitelné)

Odpovíme do 72 hodin a budeme vás informovat o průběhu řešení.
